                                                                          
                                                        FIRST GUI PROJECT

About the Project:
FirstGUIProject is a basic GUI application built using Windows Forms in C#. The project allows users to enter text in a textbox, and upon clicking a button, the application displays the entered text in a message box.


Purpose of the Project                                                    
The purpose of FirstGUIProject is to demonstrate the fundamentals of creating a desktop GUI application using WinForms in C#.                              
Interacting with user inputs through controls like textboxes and buttons, Handling events (button clicks) in Windows Forms, Displaying output dynamically using message boxes.


Features                                                                 
Dynamic Text Input: Allows users to input text through a textbox.                                                                                                               
Interactive Button: Displays the entered text in a message box upon clicking the button.                                                                              
Simple and Intuitive UI: Clean and user-friendly interface using Windows Forms.

Technologies Used
C#: Programming language used for the application,                                    
Windows Forms: Framework for creating desktop GUI applications.                                       
Visual Studio: IDE used for development.
